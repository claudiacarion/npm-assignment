# 🌏 Discover Macau - NPM Project

A modern travel guide website showcasing the culture, heritage, attractions, and cuisine of Macau — where East meets West.

🔗 **Live Site:** https://discover-macau.vercel.app/

---

## 📖 About The Project

Discover Macau is a responsive travel website designed to introduce users to the activities and foods of Macau. The site highlights famous landmarks, cultural experiences, and must-try local foods in a clean and easy-to-navigate layout.

## ✨ Features

- 🏠 **Home Page**
  - Introduction to Macau
  - Overview of what visitors can explore

- 🗺️ **Explore Page**
  - Famous attractions
  - Cultural & historical landmarks
  - Tourist highlights

- 🍜 **Eat & Drink Page**
  - Local cuisine
  - Popular dishes
  - Food culture insights

- 📱 **Responsive Design**
  - Mobile-friendly
  - Optimized for different screen sizes

- 🚀 **Fast Deployment**
  - Hosted on Vercel

---

## 🛠️ Technologies

- EJS
- Express

- Vercel
